## Features

- **Dark / Light theme** — persisted via `localStorage`, with instant apply on load to prevent flash
- **Smooth scroll navigation** — active link tracking based on scroll position
- **Mobile-responsive menu** — hamburger toggle with auto-close on resize or outside click
- **Scroll animations** — fade-in elements powered by the `IntersectionObserver` API
- **Glassmorphism UI** — card components with a frosted-glass aesthetic
- **No dependencies** — pure HTML, CSS, and JavaScript; no frameworks or build step required

## Sections

| Section | Description |
|---|---|
| Hero | Introduction, tech stack summary, and CTAs |

| Profiles | Links to Email, LinkedIn, GitHub, and Instagram |

## Project Structure

```
myWebsite/
├── index.html              # Single-page app entry point
├── assets/
│   └── images/             # Image assets (webp)
│       ├── me.webp
│       └── company-logo.webp
├── css/
│   ├── variables.css       # CSS custom properties and theme tokens
│   └── style.css           # Layout, components, and animations
└── js/
    └── main.js             # Theme, navbar, and scroll animation logic
```

## Customization

| What | Where |
|---|---|
| Colors and theme tokens | `css/variables.css` |
| Page content and sections | `index.html` |
| Animations and layout | `css/style.css` |
| Navbar, theme toggle, scroll logic | `js/main.js` |
